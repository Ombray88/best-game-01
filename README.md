Mothlight — guide Luma, a lantern moth, through a luminous night garden. Collect glowing pollen orbs, build combos, dodge drifting thorn shards and hunting bats, and grab shield, slow-time and magnet power-ups. Three lives, rising levels, synthesized WebAudio sound, and a best score that persists in your browser.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```

Or serve the `game/` folder with any static HTTP server and open `game/index.html`. No build step, no network requests — it runs fully offline. Move with the mouse or Arrow Keys / WASD. Space or click to start, P to pause, M to mute.
